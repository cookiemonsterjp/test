# Notion プロジェクト管理ワークスペース作成スキル

## 概要

このスキルは、Notionに新しいプロジェクト管理ワークスペースを作成します。
引数: `$ARGUMENTS` として `<プロジェクト名> <親ページID>` を受け取ります。

## 前提条件

- `.claude/settings.json` にNotion MCP設定とAPIキーが設定済みであること
- Node.js (v18+) がインストール済みであること
- 親ページIDのNotionページにインテグレーションが接続済みであること

## 実行手順

`$ARGUMENTS` の1番目をプロジェクト名、2番目を親ページIDとして使用してください。
引数がない場合はユーザーに確認してください。

### ステップ1: メインプロジェクトページ作成

親ページID配下に、プロジェクト名のページを作成:
- アイコン: 🚀
- POST /v1/pages

### ステップ3: タスク管理DB作成（リレーション付き）

📋 タスク管理 を作成:

### ステップ4: リレーション追加（PATCH）

1. タスク管理に自己参照リレーション追加（依存タスク/後続タスク）
2. リスク管理 → タスク管理（関連タスク/関連リスク）
3. 議事録 → マイルストーン（関連マイルストーン/関連議事録）
4. ドキュメント管理 → マイルストーン（関連マイルストーン/関連ドキュメント）

### ステップ5: ロールアップ追加（PATCH）

1. マイルストーンに「タスク数」ロールアップ（関連タスクのcount）
2. チームメンバーに「タスク件数」ロールアップ（担当タスクのcount）

### ステップ6: コンテンツ追加

- メインページにプロジェクト概要（callout + KPI + スケジュール表）
- サブページ作成: プロジェクト計画書、設定ガイド、ナレッジベース

## API呼び出し方法

JSONボディが長い場合は `/tmp/` にJSONファイルを書き出し、`curl -d @/tmp/filename.json` で送信すること。
APIキーは `.claude/settings.json` の `OPENAPI_MCP_HEADERS` から取得すること。

```bash
curl -s -X POST 'https://api.notion.com/v1/databases' \
  -H 'Authorization: Bearer <API_KEY>' \
  -H 'Notion-Version: 2022-06-28' \
  -H 'Content-Type: application/json' \
  -d @/tmp/db_config.json
```

## ユーザーへの案内事項

作成完了後、以下のビューをNotion UIで手動作成するようユーザーに案内:
1. タスク管理DBの**タイムラインビュー**（`期間`プロパティ）→ ガントチャート
2. タスク管理DBの**ボードビュー**（`ステータス`でグループ化）→ カンバン
3. 議事録DBの**カレンダービュー**（`開催日`）
4. 必要に応じて`select`→`status`プロパティに変換
